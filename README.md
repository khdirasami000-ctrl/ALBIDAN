# ALBIDAN AI Lab | مختبر البيظان للشعر الحساني والغناء التوليدي

An AI-powered platform dedicated to preserving, analyzing, and globalizing Moroccan Hassaniya poetry (Lghna, Gaf, Tal'aa, Tebraa) and traditional Azawan musical heritage.
